# ❓ Quiz App

A multiple-choice quiz app with general-knowledge questions. Answer each question, submit, and see your final score at the end.

## ✨ Features

- Questions loaded dynamically from a JavaScript array
- Four options per question with radio-button selection
- Score tracking and a **results screen** at the end
- **Play Again** button to restart the quiz
- Easy to extend — just add more objects to `quizData` in `script.js`

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (Vanilla)
